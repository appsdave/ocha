## Goal (refined)

Remove the grey left-border "shell" that appears on the highlighted/active task
list item when the `ListView` is **not** focused.  Currently the highlight state
(`ListView > ListItem.--highlight`) draws a `border-left: thick #928374` (grey)
side-line even when the list is unfocused.  Because the focused state already
uses a bright green border (`#b8bb26`), the grey border is redundant visual
noise.  After the change, only the **focused** highlight should show a coloured
side-line; the unfocused highlight should have no border decoration at all.
